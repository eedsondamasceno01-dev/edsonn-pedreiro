GERAR O APK ONLINE PELO GITHUB

1. Entre em github.com e crie uma conta, se ainda não tiver.
2. Clique em New repository.
3. Dê um nome, por exemplo: EdsonPedreiro.
4. Marque Public ou Private e clique em Create repository.
5. Clique em “uploading an existing file”.
6. Envie TODOS os arquivos e pastas deste projeto, incluindo a pasta .github.
7. Clique em Commit changes.
8. Abra a guia Actions.
9. Clique no fluxo “Gerar APK Android”.
10. Clique em Run workflow > Run workflow.
11. Aguarde a compilação terminar.
12. Abra a execução concluída.
13. Na seção Artifacts, baixe “EdsonPedreiro-APK”.
14. Extraia o ZIP baixado. Dentro estará app-debug.apk.
15. Envie o APK para o celular e instale.

IMPORTANTE
- O GitHub pode pedir para ativar Actions na primeira vez.
- Se aparecer erro, tire uma foto da tela ou copie o texto do erro e envie aqui.
